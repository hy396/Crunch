## 三、详细任务规划

### Week 1: 基础体验完善 (2/6 - 2/12)

**目标**: 让玩家能稳定登录并进入对战

| 优先级 | 任务 | 预计耗时 | 验收标准 |
|--------|------|----------|----------|
| P0 | EOS登录稳定性修复 | 2d | 连续10次登录/退出无卡住 |
| P1 | 断线重连机制 | 2d | 掉线后30秒内可重连回战局 |
| P1 | 返回主菜单完善 | 1d | 从战局返回后状态清理完整 |
| P2 | 加载界面优化 | 1d | 添加进度条和加载提示 |

**技术要点**:
- 添加登录超时机制（30秒）
- 房间人数通过SessionSettings.GetNumPublicConnections()实现
- 断线检测使用AGameModeBase::PreLogin和Logout

---

### Week 2: 防御塔系统 (2/13 - 2/19)

**目标**: 实现可配置、可扩展的防御塔系统

| 优先级 | 任务 | 预计耗时 | 验收标准 |
|--------|------|----------|----------|
| P0 | 防御塔属性集(ATowerAttributeSet) | 1d | 血量、攻击力、攻击速度、射程属性 |
| P0 | 基础攻击逻辑 | 2d | 自动索敌、攻击优先级、伤害计算 |
| P0 | 塔类型配置表 | 1d | DataTable驱动，支持3种塔类型 |
| P1 | 小地图图标显示 | 1d | 友军/敌军塔不同颜色标识 |
| P1 | 塔摧毁特效+通知 | 1d | 全屏通知、经验奖励分配 |
| P2 | 塔升级/维修系统 | 2d | 玩家可操作，消耗金币 |

**防御塔类型设计**:
```
1. 箭塔 - 高攻速、单体、对英雄有效
2. 炮塔 - 低攻速、AOE、对小兵有效
3. 水晶塔 - 辅助、给友军加buff
```

**攻击优先级算法**:
```cpp
优先级 = (是否在攻击友军 ? 100 : 0) + (是否英雄 ? 50 : 0) + (血量百分比 < 0.3 ? 30 : 0)
```
